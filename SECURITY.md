# Security policy

This is an early research foundation and is not ready to protect production systems. No released version currently carries a security-support commitment.

Do not post exploitable vulnerabilities, credentials or private data in public issues. If GitHub's private vulnerability reporting is enabled, use the repository Security → Advisories → Report a vulnerability flow. If that option is absent, a private reporting channel is not yet configured; request one without disclosing exploit details. No contact address is invented here.

Security scope and limitations are in docs/THREAT_MODEL.md. Research findings use synthetic data and controlled environments. Candidate workloads must not run with personal data, broad secrets or trusted host access.
