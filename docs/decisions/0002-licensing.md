# ADR 0002: License decision pending

Status: pending founder decision.

The project intends to offer an open-source core and optional commercial services. The original repository has no license, and this foundation preserves that state. No open-source rights are granted merely by publishing source.

Before distributing packages or inviting external contributions, Dillon should choose a license and decide whether paid value comes from services, hosting, additional modules or another model. Permissive and copyleft choices have different obligations and business implications; resolve them deliberately, with legal advice if needed.

Acceptance: add the selected license text, update package metadata and README, define contribution terms, and audit incorporated third-party task/code licenses. Until then, do not market the repository as licensed open source or publish a release.
