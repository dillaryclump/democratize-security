# Contributing

Read AGENTS.md and docs/DEVELOPMENT.md. Start with a bounded issue, use a branch and submit a PR with the requirement, change, tests and limitations. Keep documentation synchronized with capability. Architecture changes require a decision record; scoring changes require a new protocol version.

Run the locked tests, lint and format checks from README. New enforcement must include useful authorized behavior and negative security cases against real PostgreSQL. Never weaken tests to improve a score. Do not include secrets, customer data or protected final assessment material.

External contribution and redistribution terms are pending the license decision. No release/package publication is configured yet.
